        Trie (Prefix Tree) Explorer

        A trie stores every query character-by-character. Prefix search is O(k) where k is the prefix length — orders of magnitude faster than O(n) linear scan.

        How it works: Type a prefix above and click Search. The trie walks down the tree one character at a time — h → o → w — and collects all stored queries under that node. The blue highlighted path in the diagram shows exactly which nodes were visited.

          Markov Chain Language Model

          A Markov chain predicts the next word from the previous N-1 words. P(wn | wn-1) for bigrams. Each edge weight is the empirical transition probability from the training corpus.

          How it works: The model looks at your last word (or last 2 for trigram) and counts how often each next word followed it in the training corpus. The bar chart shows those probabilities — wider bar = more likely next word.

            LSTM Equations
            ft = sigmoid(Wf * [ht-1, xt] + bf)
            it = sigmoid(Wi * [ht-1, xt] + bi)

            ht = ot * tanh(ct)

            Gradient Descent on Loss Surface

            Gradient descent minimizes the loss by moving in the direction of the negative gradient: theta = theta - eta * grad(L). The surface is the Rosenbrock function. Watch the trajectory converge to the global minimum at (1, 1).

            theta_t+1 = theta_t - eta * grad(L)
            Vanilla SGD update
            L(w1,w2) = (1-w1)^2 + 2(w2-w1^2)^2
            Rosenbrock function

            Gradient-Boosted Decision Trees (GBDT)

            GBDT builds trees sequentially, each fitting the residual of the previous: Fm(x) = Fm-1(x) + eta * hm(x). Used by Bing and Yandex for query ranking.

            How it works: 16 features are extracted from your query (length, word count, keyword flags, corpus frequency). 50 decision trees each vote. The Feature Contributions bars below show which features drove the ranking score most — longer bar = bigger impact.

            Boosting Formula
            F0(x) = argmin sum L(yi, gamma)
            rim = -[dL(yi, F(xi)) / dF(xi)]
            Fm(x) = Fm-1(x) + eta * hm(x)
